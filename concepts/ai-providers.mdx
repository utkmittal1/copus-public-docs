An AI provider is the service that runs the AI model Copus works with. Copus is the assistant you talk to, and Copus sends each turn of the conversation to the provider. Copus needs at least one provider set up before it can run a task.

You set up a provider in one of two ways. You sign in to Claude Code or Codex, or you add an API key for Anthropic or OpenAI.

This page covers how to:

- [Find the providers in Settings](#find-the-providers-in-settings), split into agents and model APIs
- [Sign in to Claude Code or Codex](#sign-in-to-claude-code-or-codex)
- [Add an API key](#add-an-api-key) for Anthropic or OpenAI
- [Choose the provider a task runs on](#choose-the-provider-a-task-runs-on)
- [Set the default provider](#what-the-default-controls) and the models it uses

## Find the providers in Settings

Open **Settings**, then **AI Providers**. The **Default AI provider** card at the top shows the provider Copus uses when you don't pick one. Below it, Copus groups the providers by how you connect them.

Claude Code and Codex sit under **Agents**. Each card shows a status: **Signed in**, **Not signed in**, or **Can't be used on this computer**. Select a card to open its panel, where you sign in. To change accounts, sign in again, and Copus replaces the credential it holds.

Anthropic and OpenAI sit under **Model APIs**. Each card shows **API key saved** or **No API key**. Select a card to add, update, or remove its key, and to see its **Available models**. Copus checks a new key with the provider before it saves the key, then offers that provider's models.

## Sign in to Claude Code or Codex

<Steps>
  <Step title="Open Claude Code or Codex">
    Under **Agents**, select **Claude Code** or **Codex**.
  </Step>
  <Step title="Sign in">
    Select **Sign in**. For Claude Code, select **Open the sign-in page**, approve Copus in your browser, paste the code your browser shows you into **Paste the code here**, and select **Submit code**. For Codex, Copus opens a browser window and waits for you to finish signing in there.
  </Step>
</Steps>

If you don't finish signing in within a few minutes, Copus ends the sign-in and shows **This sign-in expired. Start again.** Select **Sign in** to start a new sign-in.

## Add an API key

<Steps>
  <Step title="Open the provider">
    Under **Model APIs**, select **Anthropic** or **OpenAI**.
  </Step>
  <Step title="Add the key">
    Paste the key into the field under the **API key** heading, then select **Save key**. Select **Where do I get a key?** to open the provider's signup page.
  </Step>
  <Step title="Check the models">
    Once Copus accepts the key, the card reads **API key saved** and the panel lists the **Available models**. Copus offers a model only where Copus supports it and your account can reach it, so you see a shorter list with a key on a lower tier.
  </Step>
</Steps>

Copus keeps the API key in your Mac's system keychain. Select **Update key** to replace the key, or **Remove key** to delete it. Copus asks you to confirm, then deletes the key and stops offering that provider's models. You can add the key again at any time.

## Choose the provider a task runs on

Under the message box, Copus shows the provider and the model a task runs on, separated by a dot. When the chat is narrow, Copus shows only the model, and you can hover over the model name to see both. Select the provider or model name to pick a different provider or model, including part way through a conversation.

Many models also have effort levels, which set how much reasoning the model does before it answers. Point at a model in the list to open its levels beside it, such as **Low**, **Medium**, or **High**. When you select the model itself, Copus picks **Medium**. For a model with only one level, Copus shows no list of levels.

A new task opens on your default provider, with the model and level set for **Conversations**. A provider or model you pick in the message box applies to that task only, so the next new task opens on the default again.

A task keeps its provider and model after you change your default. A scheduled or multi-step task runs on the default provider too, with the model set for that kind of work. You can pick another for one task on its page. See [Scheduled tasks](/autonomous/autonomous-tasks#run-pause-and-watch-a-task).

## What the default controls

Your default provider runs everything you don't pick a provider for: new tasks, scheduled and multi-step tasks, and the work Copus starts on its own. That work includes the tasks on the Home page and Copus's checks of your mail. See [Work Copus starts before you ask](/working/before-you-ask).

[Help and Side chat](/working/describing-what-you-need#ask-in-help-or-side-chat) also run on the default provider. Each message you send there uses the provider that is the default at that moment.

To change the default, select **Change** on the **Default AI provider** card and pick another provider. You can pick only a provider you have signed in to or added a key for. One provider is always the default. The change applies to work that starts after it.

### The models the default uses

Copus picks a model and an effort level for each kind of work on the default provider. Under **Models**, **Use defaults** is selected. Copus moves its picks to newer models as they come out.

To choose your own, select **Customize**. The card lists each kind of work, such as **Conversations**, **Scheduled tasks**, and **Checking email**, with a model and level for each. Copus keeps its own picks for the ones you leave alone. Select **Reset** to put one back, or **Use defaults** to go back to Copus's picks for all of them. Select **Done** to keep your changes, or **Cancel** to undo them. Select **Customize** again to open or close the list. Copus keeps your choices for each provider, so they come back when you make that provider the default again.
